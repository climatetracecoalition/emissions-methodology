# Sector Methodologies

Detailed, sector-specific documentation of how Climate TRACE estimates greenhouse gas emissions.

| Folder | What's in it |
|---|---|
| **[1-Sectors](./1-Sectors/)** | The ten emissions sectors. Start here. |
| **[2-Cross-Cutting](./2-Cross-Cutting/)** | Methods that apply across every sector |
| **[3-Archive](./3-Archive/)** | Superseded documents, retained for citation |

Each sector folder lists its subsectors using the same slugs that appear in the
[data downloads](https://climatetrace.org/data), so you can go from a row in a CSV to the
document behind it.

## Versioning

Methodologies are versioned with git tags. Every data release is tagged, so you can cite a fixed
state of these documents rather than a moving `main` branch.

Changelogs for each release are in [`Changelogs/`](../Changelogs/).
