# Changelogs

What changed in each Climate TRACE data release. The database updates at the end of every month.

Included within each changelog folder are the monthly (version) data licensing and schema update. If a release has no updates from the previous month, use last release's  schema.

**Current release: v5.12.0 (October 2026)** — see [V5.X](./V5.X/).

| Folder | Releases |
|---|---|
| [V5.X](./V5.X/) | v5.0.0 – v5.11.0 |
| [V4.X](./V4.X/) | v4.1.0 – v4.8.0 |

Sectors with no changes in a given month/version do not appear in that month/version's changelog. A sector with
substantial methodological changes will have its methodology document revised in the same release or fater;
those live in [`Sector-Methodologies/`](../Sector-Methodologies/).
